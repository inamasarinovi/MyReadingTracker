## My Reading Tracker
## Deskripsi
My Reading Tracker adalah aplikasi Android sederhana untuk mencatat buku dan memantau progres membaca.

## Fitur
- Memasukkan judul buku dan nama penulis.
- Menghitung jumlah halaman yang telah dibaca.
- Mengatur status selesai membaca menggunakan Switch.
- Memvalidasi input sebelum buku disimpan.
- Menampilkan pesan setelah buku berhasil disimpan.
- Mengatur ulang formulir menggunakan tombol Reset.

## Teknologi
- Kotlin
- Jetpack Compose
- Material 3
- Android Studio

## Cara Menjalankan
1. Buka proyek MyReadingTracker di Android Studio.
2. Tunggu hingga proses Gradle Sync selesai.
3. Jalankan aplikasi pada emulator Android atau perangkat yang kompatibel.
